下载之后

系统版本不同，提示文字可能略有差异。遇到拦截，按下面的步骤处理即可。

01

Android

点击下载后，如提示「禁止安装未知应用」，在浏览器或文件管理器的设置里允许安装，再重新打开 APK 完成安装。

02

iOS

在电脑安装 AltStore 或 Sideloadly，连接 iPhone 后导入 IPA，用 Apple ID 自签。再到「设置 → 通用 → VPN 与设备管理」信任开发者。

03

macOS

打开 DMG，把「芥菜种教会」拖入「应用程序」。首次启动若提示未验证开发者，右键点击应用选择「打开」。

04

Windows

解压 ZIP 后进入 Mustardseed 文件夹，双击 Mustardseed.exe。若出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

iOS 为无签名构建，macOS 与 Windows 为未公证构建，因此需要上述手动确认；应用本身功能完整。
